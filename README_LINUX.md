# 🐧 Running Chrome Dino on Linux

## Option 1: 1-Click Native Linux Build & Run
Open your terminal in this directory and run:
```bash
chmod +x build_and_run_linux.sh
./build_and_run_linux.sh
```
*(Automatically configures CMake, compiles with Qt6, and launches the native pure raster engine).*

## Option 2: Instant Play in Browser (Zero Build Needed)
Double-click `index.html` or run:
```bash
xdg-open index.html
```
*(Runs the complete pure raster engine in Chrome/Firefox with 100% feature parity).*
